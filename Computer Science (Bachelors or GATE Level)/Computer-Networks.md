# Computer Networks

Computer Network is a collection of autonomous devices interconnected via a medium.

Open Systems Interconnection (OSI) Model:

[OSI Model](https://en.wikipedia.org/wiki/OSI_model) comprises of the seven layers:

Physical Layer <-> Data Link Layer <-> Network Layer <-> Transport Layer <-> Session Layer <-> Presentation Layer <-> Application Layer.

- Mnemonic: APSTNDP (starting with the Application Layer, then Presentation, Session, Transport, Network, Data Link and Physical).

[Transmission Control Protocol (TCP)](https://en.wikipedia.org/wiki/Transmission_Control_Protocol) / [Internet Protocol (IP)](https://en.wikipedia.org/wiki/Internet_Protocol) stack

TCP/IP stack comprises of the four layers:

Application Layer <-> Transport Layer <-> Internet Layer <-> Network Interface
